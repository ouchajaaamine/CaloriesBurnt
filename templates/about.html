About This Project

Project Overview

The Calorie Burnt Prediction project uses machine learning to accurately predict how many calories an individual will burn during exercise. The prediction model is trained on a dataset of over 15,000 exercise records that include various personal metrics and corresponding calorie burn data.

How It Works

Our system uses a Linear Regression model trained on exercise data to make predictions. The model takes into account several important factors:

  • Personal metrics: Age, gender, height, and weight
  • Exercise intensity: Duration, heart rate, and body temperature

These factors collectively provide a comprehensive picture of an individual's physical condition and exercise intensity, allowing for accurate calorie burn predictions.

Dataset

The model is trained on a comprehensive dataset containing exercise records with the following features:

  • User ID
  • Gender
  • Age
  • Height
  • Weight
  • Duration
  • Heart Rate
  • Body Temperature
  • Calories Burned
